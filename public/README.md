# 静的アセット (public)

ブラウザから直接アクセス可能なファイル（画像、アイコンなど）を配置するフォルダです。
ビルド時には、ここにあるファイルはそのまま出力先（dist）にコピーされます。

## ファイル一覧

- **`favicon.ico`**, **`logo.jpg`**: アプリケーションのアイコンやロゴ画像。
- **`menu_a.png`** 〜 **`menu_d.png`**: トレーニングメニュー選択画面で表示される背景画像。
- **`celebration.png`**: 目標達成時に表示される祝いの画像。
- **`squat.png`**: スクワットメニューやバナーで使用される画像。
