# ソースコード (src)

アプリケーションの主要なロジックや画面デザインを記述するファイルが含まれています。

## ファイル説明

- **`App.jsx`**: アプリケーションのメインロジックがすべて記述されています。
  - 状態管理（履歴、メニュー、予約など）
  - 画面描画（ホーム、カレンダー、設定、トレーニング画面）
  - シェア機能、データ永続化（localStorage）
- **`main.jsx`**: Reactアプリケーションのエントリーポイントです。`App.jsx` を読み込んでブラウザに表示します。
- **`index.css`**: Tailwind CSS の基本設定やグローバルスタイルが記述されています。

## 技術スタック
- **React**: UIライブラリ
- **Tailwind CSS**: スタイリング
- **Lucide React**: アイコン
- **html2canvas**: シェア用画像生成
